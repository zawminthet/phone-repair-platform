# Phone Repair Training Platform

スマートフォン修理の学習から、故障診断、仮想修理、動作テストまでを一つのWebアプリで体験できるトレーニングプラットフォームです。

A web-based training platform for learning smartphone repair: study, diagnosis, virtual repair, and hardware testing.

## Status

🚧 開発中 — Phase 1：開発環境の構築

In development — Phase 1: Development environment

## Tech Stack

- HTML / CSS / JavaScript
- PHP 8.2
- MySQL (MariaDB) — 予定 / planned
- Three.js — 予定 / planned

## Planned Features (V1)

- 学習モード / Study Mode
- 技術用語辞書（英語・ミャンマー語・日本語）/ Technical Dictionary (EN / MY / JA)
- 部品データベースと互換性チェック / Component database & compatibility check
- 仮想ワークベンチと修理ワークフロー / Virtual workbench & repair workflow
- トラブルシューティングセンター / Troubleshooting Center
- 3Dスマホビューア / 3D phone viewer
- 修理費用シミュレーター・修理履歴 / Repair cost simulator & repair history

## Local Setup

1. XAMPP（PHP 8.2）をインストールする
2. リポジトリを XAMPP の `htdocs` にクローンする（macOS の場合）

   ```bash
   cd /Applications/XAMPP/xamppfiles/htdocs
   git clone https://github.com/zawminthet/phone-repair-platform.git
   ```

3. XAMPP で Apache を起動する
4. ブラウザで開く：http://localhost/phone-repair-platform/public/
